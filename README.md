# 🎓 School Hub - Student Management System

A student and teacher management web application built with Python and Streamlit using Claude to ake the front end.

The project allows users to register students and teachers, manage student grades, and search for individual records through an interactive web interface.

# 🚀 Features

- 🧑‍🎓 Register students
- 🧑‍🏫 Register teachers
- 📊 Add and manage student grades
- 🔍 Search for students by roll number
- 🔍 Search for teachers by employee ID
- 📈 Calculate student grade averages
- 💾 Store data using JSON
- 🎨 Custom Streamlit interface
- ✉️ Basic email validation
- 🔐 Prevent duplicate student roll numbers and teacher IDs

# 🛠️ Technologies Used

- Python
- Streamlit
- JSON
- Object-Oriented Programming (OOP)
- HTML/CSS (Claude)
